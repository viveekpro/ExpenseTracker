# ExpenseTracker

 ## Barrownz Group

 **ExpenseTracker** is a full-stack **MERN application** designed to help users manage and track their expenses in an organized way.

 ### 🚀 Tech Stack

 **Frontend**

 - React.js
- JavaScript
- HTML5
- CSS3

 **Backend**

 - Node.js
- Express.js
- MongoDB
- REST API

 ### ⚙️ Installation

 Clone the repository:

```
git clone <repository-url>
cd ExpenseTracker
```

 #### Backend

```
cd backend
npm install
```

 Create a `.env` file:

```
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

 Start the backend:

```
npm run dev
```

 #### Frontend

 Open another terminal:

```
cd frontend
npm install
npm start
```

 ### 🔐 Environment Variables

 Keep sensitive information such as database credentials and API keys inside `.env` files.

 Do **not** commit `.env` files to Git.

 ### 📦 Main Features

 - Add and manage expenses
- Track spending
- Backend REST APIs
- MongoDB database integration
- React-based frontend
- Separate frontend and backend architecture
